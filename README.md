# SkyWay Tours & Travels

React.js + Vite + Tailwind CSS + Lucide React travel website starter.

## Included pages
- Home
- Destinations
- Packages
- About
- Contact
- 404 fallback

## Run
npm install
npm run dev

## Production build
npm run build

Replace demo phone/email/address and Unsplash image URLs with your real business data.
